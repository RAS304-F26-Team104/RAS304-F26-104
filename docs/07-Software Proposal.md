## Introduction

This document proposes the software state machines and execution logic for the **Team 104 Smart Gripper**. It details the peripheral initialization, sensor polling, and UART communication protocols across all system nodes.

## System Nodes

- Board 1: Master Node
- Board 2: Grip Node
- Board 3: Tactile Node
- Board 4: Proximity Node
- Board 5: Slip Detection Node
